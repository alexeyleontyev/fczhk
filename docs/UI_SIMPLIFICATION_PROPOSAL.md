# Компактный интерфейс приложения

Реализовано 19.10.2026 по выбранному варианту: вкладки, компактные таблицы и подробности по нажатию. Основные разделы приложения сохранены; права, расчёты и серверные операции не менялись.

## Игроки

- «Каталог» открывается первым: один поиск и строки с именем, атакой, защитой и суммой. Нажатие раскрывает оценки по амплуа, статистику, оценивание и доступные администратору действия.
- «Зачёты» показывает одну таблицу выбранного показателя за текущий сезон или всю историю. Сохраняются выбор показателя, минимальное число игр и одинаковое место при равных значениях.
- «Рейтинги» переключается между сообществом и OpenSkill. Обе оценки общие для всех сезонов; сезонный фильтр здесь не показывается. Поиск общий для всех вкладок раздела.
- «А» и «З» обведены кружками, в том числе в отдельной таблице сообщества. Для вратарского показателя выводится только защита. Отсутствующая оценка не подменяется нулём.
- Рейтинги загружаются при открытии соответствующей вкладки; каталог не запускает запросы всех таблиц заранее.

## Игра и составы

Дата, время, место и состояние сбора остаются видны. Внутри игры доступны:

| Вкладка | Содержание |
| --- | --- |
| Обзор | Моя запись, места, оплата и главное действие администратора по стадии. Прогноз и справка раскрываются отдельно. |
| Участники | Полевые, вратари, очередь, резерв, оплаты, добавление из каталога и оценки на одну игру. Время записи находится в подробностях строки. |
| Итог | Счёт, голы, передачи, фактические участники и редактор результата. Составы и замены раскрываются по нажатию. Доступна после утверждения команд. |
| Управление | Параметры, отмена, история и публикации; только для администратора. Ошибки доставки остаются заметны на обзоре. |

Тактическая доска открывается через «Составы» и сохраняет личные варианты, перенос игроков, расстановку по соотношению атаки и защиты и подтверждение администратором. Аукцион остаётся отдельным экраном: ставки и бюджеты на виду, составы с ценами, история и управление раскрываются отдельно.

## Архив, профиль и прогнозы

Архив представлен строками: дата, сезон, число игроков, счёт и статус. Нажатие открывает игру. Сохраняются сезонный фильтр, загрузка следующих страниц и возврат к прежнему месту списка. Статус отменённой или незавершённой игры виден также на телефоне.

В профиле — «Статистика», «Оценки», «Настройки». Изменение alias и привязка исторической карточки находятся в настройках; выход доступен отдельно. В статистике игрока одновременно открыт один блок: «Обзор», «Матчи» или «Партнёры». Период общий с каталогом, архивом и зачётами.

Зачёт прогнозов остаётся компактной таблицей. Правила конкурса и детализация начисленных очков раскрываются по запросу. Дедлайны, запрет просмотра чужих прогнозов до начала игры и пересчёт по результату сохранены.

## Управление клубом

«Расписание» содержит шаблон и раскрываемые пропуски недель. «Профили» — заявки на объединение карточек. «Администраторы» видны только владельцу. «Диагностика» — доставка сообщений и повторы. Списки и опрос диагностических данных загружаются только при открытии соответствующего подраздела.

Общий компонент вкладок поддерживает клавиатуру: стрелки, Home и End, корректные роли tab/tabpanel и связь выбранной вкладки с содержимым. Экран адаптирован для ширины от 320 пикселей; основные действия не требуют наведения мыши.

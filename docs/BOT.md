# Telegram-бот: текущее поведение

Актуализировано 28.10.2026. [Оглавление](README.md) · [Настройки](CONFIGURATION.md) · [Эксплуатация](DEPLOYMENT_PLAN.md).

Этот документ описывает реализованные команды и действия бота. Возможности Mini App и предложения из [ТЗ](TECHNICAL_SPECIFICATION.md) шире; ниже перечислено то, что обрабатывает бот сейчас.

## Доступ и регистрация

При выполнении команды или нажатии кнопки записи бот проверяет, состоит ли Telegram-пользователь в настроенном сообществе. При первой успешной проверке он находит карточку по числовому Telegram ID либо создаёт новую с именем пользователя из Telegram. Исторический профиль по совпадению имени автоматически не привязывается. Если проверить членство не удалось, действие отклоняется.

Владелец задаётся через `FCZHK_OWNER_ID` и также должен состоять в сообществе. Других администраторов он назначает и снимает в Mini App или на сайте: «Управление → Администраторы». Кандидат должен сначала войти через Telegram. Обычный администратор не управляет ролями; команды бота для назначения ролей нет. Решения сохраняются в БД и применяются со следующего запроса без перезапуска. Для старой конфигурации первый ID в `FCZHK_ADMIN_IDS` становится владельцем, пока явный владелец не задан.

Игрок выбирает свою историческую карточку в разделе профиля Mini App и отправляет заявку. Администратор проверяет личность и подтверждает связь в настройках; также доступна прямая привязка из справочника игроков. Совпадение имени само по себе не подтверждает личность. Отдельной команды бота для выбора исторического профиля нет.

В обычном браузере доступен отдельный вход на сайт через Telegram Login после [настройки Client ID в BotFather](../README.md#вход-на-сайт-через-telegram). Он использует ту же проверку подписки на канал или участия в чате и находит ту же карточку по числовому Telegram ID. Этот вход не требует команды боту; автоматическая привязка истории по имени не выполняется.

## Команды

| Команда | Что происходит |
|---|---|
| `/start` | Проверяет доступ, создаёт карточку при первом входе и отправляет приветствие с кнопкой «⚽ Открыть приложение». |
| `/help` | Краткая памятка по командам и кнопке «Я оплатил» в `/game`. |
| `/profile` | Показывает имя игрока, Telegram-никнейм `@username` либо числовой Telegram ID при его отсутствии и два блока статистики: за всё время и за текущий сезон. В каждом — игры, победы, ничьи, поражения, голы, ассисты и «гол + пас». Учитывается история связанных карточек. Текущий сезон — календарный год по Москве; при отсутствии игр показаны нули. |
| `/game` | Показывает ближайшую будущую опубликованную игру: дату и время по Москве, место и актуальный статус. До утверждения команд — основной список полевых и вратарей и отдельный блок «Резерв», после утверждения — только утверждённые команды «Белые» и «Чёрные» с отметкой вратарей. При отсутствии игры сообщает об этом. |
| `/lastgame` | Результат последней завершённой игры: фактический счёт, составы с отметкой вратарей, голы, ассисты и автоголы. Учитывает последние исправления результата; незавершённые, отменённые и будущие игры пропускает. |
| `/admin` | Обрабатывается тем же приветственным обработчиком, что `/start`; отдельного административного меню в боте нет. В меню команд Telegram эта команда не объявляется. |

После перевода участник нажимает «Я оплатил» в ответе на `/game`. Кнопка появляется у записанного игрока, в том числе после финализации и утверждения составов. После нажатия подпись меняется на «Оплачен»; оплата считается подтверждённой только после действия администратора. Повторное нажатие не меняет очередь и не создаёт дубли. Кнопка привязана к конкретной игре и записи: чужая или устаревшая после отмены и повторной записи кнопка не меняет оплату. В строке игрока `/game` остаются два кружочка без текстовых подписей: сначала отметка игрока, затем подтверждение администратора; зелёный означает наличие отметки, красный — отсутствие. До утверждения также показаны номер в очереди и время записи, после — номер внутри команды без времени записи. Каждый новый вызов читает текущий статус и состав, в том числе после смены цветов команд или отмены утверждения.

После `fczhk configure-bot` меню команд Telegram содержит `/start`, `/game`, `/lastgame`, `/profile` и `/help`. Команды `/paid` и `/players` удалены из меню и обработчиков; каталог игроков доступен в Mini App. При выпуске обновления нужно повторить `configure-bot`, чтобы Telegram обновил сохранённое меню команд.

## Кнопки и публикации

- В приветствии, `/help`, `/profile`, `/lastgame` и ответе `/game` есть кнопка «⚽ Открыть приложение», ведущая в Mini App. Ответы `/game` и `/lastgame` ведут сразу к карточке соответствующей игры, если настроен username бота. Кнопка меню Telegram «Открыть клуб» тоже ведёт в Mini App.
- Если ближайшая игра имеет статус открытого сбора, ответ `/game` содержит кнопки «Записаться полевым», «Записаться вратарем» и «Отменить запись». Нажатие записывает игрока в выбранное амплуа; повторное нажатие для той же записи не создаёт дубль. При смене амплуа обновляется время записи. После закрытия сбора самостоятельная запись недоступна. Повторная доставка старого callback не отменяет новую запись.
- Подтверждение оплаты администратором, управление составами, оценки, результаты, прогнозы, аукцион и подробная статистика выполняются в Mini App. Участник сообщает об оплате кнопкой «Я оплатил» в Mini App или в ответе `/game` бота.
- В посте утверждённых составов добавлена кнопка «Сделать прогноз»: она открывает верхнюю форму конкретной игры через `startapp=game_{id}_prediction`. Без username бота используется браузерная ссылка с `game` и `screen=prediction`.
- Отдельный worker публикует от имени бота пост об открытии записи, пост утверждённых составов и итог завершённой игры с составами, голами и ассистами в настроенный чат или канал. У последней части поста есть кнопка «Открыть игру». При изменении состава или параметров worker пытается пометить устаревший пост. При отмене уже открытой будущей игры worker отправляет причину отмены и напоминание согласовать возвраты; отмена черновика сообщения не создаёт. Анонсы, напоминания об оплате и расширенные сообщения настраиваются в [настройках](CONFIGURATION.md).

## Настройка и запуск

Параметры Telegram задаются через `.env`; порядок подключения приведён в [README](../README.md#реальное-подключение-telegram). Команда `uv run fczhk configure-bot` явно настраивает список команд, кнопку меню и способ приёма обновлений:

- Если задан `FCZHK_WEBHOOK_SECRET`, Telegram отправляет сообщения и нажатия кнопок на `/api/telegram/webhook`; API проверяет секретный заголовок.
- Без `FCZHK_WEBHOOK_SECRET` используется отдельный процесс `uv run fczhk bot` с polling. Одновременно включать webhook и polling не нужно.
- Для публикаций и расписания отдельно запускается `uv run fczhk worker`.

Локальное демо работает без подключения к Telegram и не отправляет реальные сообщения.

## Контроль доставки

Администратор видит состояние очереди, ошибки и неопределённые доставки в настройках приложения. Для `uncertain` сначала проверить чат, затем явно повторить отправку; иначе возможен дубль. Ошибку редактирования старого поста можно повторить отдельно. `uv run fczhk check-bot` читает состояние webhook и возвращает ненулевой код при неверном URL или свежей ошибке; команда не меняет настройки и применяется только в webhook-режиме.

Выход в Mini App/браузере отзывает текущую серверную сессию; повторный вход возвращает тот же профиль по Telegram ID. Worker удаляет просроченные сессии. Прямые ссылки на игру сохраняются при входе.

Игровое имя уникально. Если имя Telegram уже занято другой карточкой, первый вход создаёт отдельный профиль с числовым суффиксом; повторный вход по Telegram ID сохраняет его. Изменить имя на занятое нельзя. Связь с историей по-прежнему подтверждает администратор.

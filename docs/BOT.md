# Telegram-бот: текущее поведение

Актуализировано 17.10.2026. [Оглавление](README.md) · [Настройки](CONFIGURATION.md) · [Эксплуатация](DEPLOYMENT_PLAN.md).

Этот документ описывает реализованные команды и действия бота. Возможности Mini App и предложения из [ТЗ](TECHNICAL_SPECIFICATION.md) шире; ниже перечислено то, что обрабатывает бот сейчас.

## Доступ и регистрация

При выполнении команды или нажатии кнопки записи бот проверяет, состоит ли Telegram-пользователь в настроенном сообществе. При первой успешной проверке он находит карточку по числовому Telegram ID либо создаёт новую с именем пользователя из Telegram. Исторический профиль по совпадению имени автоматически не привязывается. Если проверить членство не удалось, действие отклоняется.

Игрок выбирает свою историческую карточку в разделе профиля Mini App и отправляет заявку. Администратор проверяет личность и подтверждает связь в настройках; также доступна прямая привязка из справочника игроков. Совпадение имени само по себе не подтверждает личность. Отдельной команды бота для выбора исторического профиля нет.

В обычном браузере доступен отдельный вход на сайт через Telegram Login после [настройки Client ID в BotFather](../README.md#вход-на-сайт-через-telegram). Он использует ту же проверку подписки на канал или участия в чате и находит ту же карточку по числовому Telegram ID. Этот вход не требует команды боту; автоматическая привязка истории по имени не выполняется.

## Команды

| Команда | Что происходит |
|---|---|
| `/start` | Проверяет доступ, создаёт карточку при первом входе и отправляет приветствие с кнопкой «⚽ Открыть приложение». |
| `/help` | Пока вызывает тот же обработчик и отправляет то же приветствие, что `/start`. |
| `/profile` | Пока вызывает тот же обработчик; личную статистику открывают в Mini App. |
| `/game` | Показывает ближайшую будущую игру, если она опубликована: дату и время по Москве, место, очереди полевых и вратарей, статус оплаты и отметку включения в состав. При отсутствии игры сообщает об этом. |
| `/players` | Показывает зарегистрированных игроков по имени и средние оценки сообщества: атаку и защиту полевого, защиту вратаря. Карточки без Telegram ID в этом списке не выводятся. |
| `/admin` | Обрабатывается тем же приветственным обработчиком, что `/start`; отдельного административного меню в боте нет. В меню команд Telegram эта команда не объявляется. |

После `fczhk configure-bot` меню команд Telegram содержит `/start`, `/game`, `/players`, `/profile` и `/help`. Наличие команды в меню не означает отдельного сценария для `/profile` или `/help`.

## Кнопки и публикации

- В приветствии и ответе `/game` есть кнопка «⚽ Открыть приложение», ведущая в Mini App. Для открытого сбора ответ `/game` ведёт сразу к его карточке, если настроен username бота. Кнопка меню Telegram «Открыть клуб» тоже ведёт в Mini App.
- Если ближайшая игра имеет статус открытого сбора, ответ `/game` содержит кнопки «Полевой» и «Вратарь». Нажатие записывает игрока в выбранное амплуа; повторное нажатие для той же записи не создаёт дубль. При смене амплуа обновляется время записи. После закрытия сбора самостоятельная запись недоступна.
- Отмена записи, подтверждение оплаты, управление составами, оценки, результаты, прогнозы, аукцион и подробная статистика выполняются в Mini App. Бот не имеет отдельных команд для этих действий.
- Отдельный worker публикует от имени бота пост об открытии записи и пост утверждённых составов в настроенный чат или канал. У последней части поста есть кнопка «Открыть игру». При изменении состава или параметров worker пытается пометить устаревший пост. При отмене уже открытой будущей игры worker отправляет причину отмены и напоминание согласовать возвраты; отмена черновика сообщения не создаёт. Публикация результатов и личные уведомления игрокам сейчас не реализованы.

## Настройка и запуск

Параметры Telegram задаются через `.env`; порядок подключения приведён в [README](../README.md#реальное-подключение-telegram). Команда `uv run fczhk configure-bot` явно настраивает список команд, кнопку меню и способ приёма обновлений:

- Если задан `FCZHK_WEBHOOK_SECRET`, Telegram отправляет сообщения и нажатия кнопок на `/api/telegram/webhook`; API проверяет секретный заголовок.
- Без `FCZHK_WEBHOOK_SECRET` используется отдельный процесс `uv run fczhk bot` с polling. Одновременно включать webhook и polling не нужно.
- Для публикаций и расписания отдельно запускается `uv run fczhk worker`.

Локальное демо работает без подключения к Telegram и не отправляет реальные сообщения.

## Контроль доставки

Администратор видит состояние очереди, ошибки и неопределённые доставки в настройках приложения. Для `uncertain` сначала проверить чат, затем явно повторить отправку; иначе возможен дубль. Ошибку редактирования старого поста можно повторить отдельно. `uv run fczhk check-bot` читает состояние webhook и возвращает ненулевой код при неверном URL или свежей ошибке; команда не меняет настройки и применяется только в webhook-режиме.

Выход в Mini App/браузере отзывает текущую серверную сессию; повторный вход возвращает тот же профиль по Telegram ID. Worker удаляет просроченные сессии. Прямые ссылки на игру сохраняются при входе.

Игровое имя уникально. Если имя Telegram уже занято другой карточкой, первый вход создаёт отдельный профиль с числовым суффиксом; повторный вход по Telegram ID сохраняет его. Изменить имя на занятое нельзя. Связь с историей по-прежнему подтверждает администратор.

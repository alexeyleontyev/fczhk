# Документация ФКЖК

Актуализировано 18.10.2026. В `main` объединены MVP 1–5, исторические результаты и оценки, браузерный вход, роль владельца с управлением администраторами, исправления надёжности и инструменты выпуска. Документация описывает код; успешные локальные проверки и CI не означают, что сервер уже развёрнут в настоящем сообществе.

Документы этапов сохраняют решения и датированные результаты проверок: [MVP 1](MVP1_IMPLEMENTATION.md), [MVP 2](MVP2_IMPLEMENTATION.md), [MVP 3](MVP3_IMPLEMENTATION.md), [MVP 4](MVP4_IMPLEMENTATION.md), [MVP 5](MVP5_IMPLEMENTATION.md). Их исходные имена веток и старые количества тестов относятся к истории разработки; текущие команды и результаты находятся в справочниках выше.

При изменении поведения обновлять соответствующее описание функций, API и ТЗ; при изменении окружения — `.env.example` и конфигурацию; при изменении выпуска — эксплуатацию и проверки. Секреты, локальные базы, XLSX и backup в Git не включать.
